# Creative Sublimation website (draft)

Custom sublimation printing: shirts, hoodies, mugs, tumblers, water bottles and pencil pouches.

## Pages
- `index.html`: opening page (animated logo, scroll showcase, English / Español switch)
- `design.html`: design tool where customers pick an item, upload a photo or describe an idea, and send a request

## Notes
- Plain HTML, CSS and JavaScript. No build step.
- Language choice is shared between pages and remembered in the browser.
- Request form is in preview mode: nothing is sent yet. Next step is connecting a form service.
- Product photos and gallery items are placeholders until real photos arrive.
